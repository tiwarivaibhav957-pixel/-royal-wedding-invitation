# Royal Wedding Invitation v2

Mobile-first animated digital invitation for Anita Kumari & Saurabh Kumar.
No database, RSVP, phone number, or admin panel.

## Update details
Edit `src/wedding.ts`.

## Run
`npm install`
`npm run dev`

## Build
`npm run build`

The invitation starts with a sealed envelope. Tapping “Open your invitation” animates the letter sliding out, the envelope opening, and the full invitation unfolding. The experience uses Framer Motion and CSS, with reduced-motion support.
